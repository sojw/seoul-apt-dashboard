# 서울 아파트 증시

**공식 실거래가로 매긴 서울 아파트 단지별 시가총액.** 주식 시총처럼 단지마다 값을 매겨 순위·등락·추이로 보여준다.

**▶ <https://seoul-apt-market.vercel.app>**

이 저장소의 GitHub Pages(`sojw.github.io/seoul-apt-dashboard`)는 **데이터만** 낸다. 첫 주소로 들어오면 위 화면으로 넘어간다.

```
단지 시총 = ㎡당 가격(최근 12개월 실거래 중위값) × 주거전용면적 합계
            ─────────── 주가 ───────────     ────── 발행주식수 ──────
```

| 2026-10-26 기준 | 값 |
|---|---|
| 서울 아파트 시총 | **약 2,693조 원** |
| 값을 매긴 단지 | 2,547곳 (149만 세대) |
| 실거래로 매긴 비율 | 95.5% (나머지는 분양권·같은 동·같은 구 추정) |
| 시총 추이 | 2016-10 ~ 2026-09, 월별 |

최신 숫자는 [`data.json`](data.json) 의 `totals` 에 있다.

> 이 저장소는 **배포 결과물**이다. 생성기(수집·산정 코드)는 비공개 저장소에 있고, 매일 이 저장소의 `main` 을
> 커밋 1개짜리로 **통째로 덮어쓴다**(force-push). 이슈·PR 로 바꾼 파일은 다음 갱신 때 사라진다.

민간 시세(KB·R114·호가)는 쓰지 않는다. 그래서 값은 **최근 12개월에 실제로 거래된 가격**이고, 지금 호가와는 다를 수 있다.

## 산정 규칙

| 규칙 | 결정 | 이유 |
|---|---|---|
| 가격 기간 | 최근 12개월 | 단지의 약 95%가 실거래로 값이 매겨진다(3개월이면 약 89%) |
| 해제 거래 | 뺀다 | 성사되지 않은 거래다 |
| 직거래 | 넣는다 | 뺄 근거를 아직 재지 않았다 |
| 임대 단지 | 뺀다 | 거래 대상이 아니다 |
| 분양·임대 혼합 단지 | 임대분 포함 | 단지 안 임대 세대수 자료가 없다(영향 추정 2~3%p) |
| 매매가 없는 신축 | 분양권·입주권 실거래로 매긴다 | 같은 동 옛 단지 시세로 추정하면 크게 낮다 |
| 철거·재건축 단지 | 뺀다 | 1995년 이전 준공 + 36개월 매매 0건 + 12개월 창에도 거래 없음. 같은 자리 새 단지와 이중으로 세지 않게 |
| 그래도 거래 없는 단지 | 같은 동 → 같은 구 ㎡당 중위가로 추정, 표시 | 값을 안 매기면 단지가 빠진다 |
| 12개월 등락 | **같은 평형끼리** 처음 3개월과 최근 3개월 비교 | 그달 거래된 평형 구성에 흔들리지 않게 |
| 평당가 | 시총 ÷ 전용면적 × 3.3 | **전용면적 기준**이라 공급면적 기준인 민간 평당가보다 높게 나온다 |

### 공식 지수와 맞는가

2024Q4 → 2025Q4, 두 분기 모두 거래된 1,776단지의 가격 변화(단지 중앙값)를 부동산원 지수와 견줬다.

| 권역 | 이 대시보드 | 부동산원 실거래가격지수 |
|---|---|---|
| 서울 | +10.3% | +11.7% |
| 동남권 | +20.2% | +20.6% |
| 서남권 | +10.8% | +10.9% |
| 도심권 | +10.7% | +16.2% |
| 서북권 | +7.6% | +10.2% |
| 동북권 | +5.2% | +8.0% |

시총 증가율이 지수보다 큰 것은 금액 가중 때문이다 — 서울 시총에서 큰 몫인 동남권이 더 올랐다.

### 알려진 한계

- 단지 목록은 K-apt **의무관리 단지** 위주다. 소형·나홀로 단지는 빠진다(실거래의 약 17%가 어느 단지와도 이어지지 않는다).
- 2022~23년 거래 절벽 구간은 실거래로 매긴 단지가 74%까지 떨어져 추정 비중이 크다.
- 분양권 실거래엔 단지 코드가 없어, 단지명이 목록과 다르면 이어지지 않는다.
- 세대수가 0 으로 등록된 신축이 있다. 시총은 면적으로 매기므로 영향이 없지만 세대수 표시는 틀린다.
- 시총 추이는 **현재 단지 목록 기준**으로 과거를 다시 매긴 값이다. 목록에서 지워진 단지는 과거에서도 빠진다.

## 데이터 파일

화면이 읽는 JSON 을 그대로 공개한다. 키 없이 바로 받을 수 있다(CORS 는 GitHub Pages 기본값).

```bash
curl -s https://sojw.github.io/seoul-apt-dashboard/data.json | jq '.totals.value'   # 억 원
```

단위: **금액 억 원**(단지·합계), **만 원**(개별 거래·가격대), **면적 ㎡**, **ppm 만 원/㎡**.
비율은 소수(0.0123 = 1.23%).

| 파일 | 크기 | 내용 |
|---|---|---|
| `data.json` | ~0.9MB | 전체 요약 + 단지 목록. 첫 화면이 이것만으로 그려진다 |
| `details.json` | ~1MB | 단지 상세(주소·관리 정보·월별 ㎡당 중위가). 상세를 열 때 받는다 |
| `trades/<구 코드>.json` | 구별 | 단지별 최근 실거래 |
| `hist/<구 코드>.json` | 구별 | 단지별 평형(소·중·대) 분기 중위가, 2016Q4~ |
| `news.json` | ~80KB | 뉴스판(이야기 묶음·단독) |
| `latest.json` | ~2KB | 속보 줄 |
| `rates.json` | ~7KB | 주담대 금리(은행별 실제 평균·구성·이력, 공시 범위, 토스 기준금리) |
| `seoul_gu.json` | | 자치구 경계(지도) |

구 코드는 법정동 코드 앞 5자리다(종로구 `11110` … 강동구 `11740`). `data.json` 의 `gus[].code` 에 있다.

### `data.json`

| 키 | 내용 |
|---|---|
| `as_of`, `generated_at` | 기준일, 생성 시각 |
| `window` | 가격 기간 `{since, months}` |
| `totals` | 서울 합계: `value`(억), `estimated_value`(추정분), `complexes`, `unvalued`, `households`, `by_basis`(근거별 단지 수), `trade_coverage` |
| `regions`, `gus` | 권역(5)·자치구(25)별 `value`·`complexes`·`households`·`estimated`. 권역엔 `official`(부동산원 지수 최근값·전년비) |
| `official` | 부동산원 지수 시계열 |
| `complex_fields` + `complexes` | 단지 표. **행은 배열**이고 열 이름은 `complex_fields` 순서다(용량 때문) |
| `brands` | 브랜드별 단지 수·시총 |
| `missing` | 시총에서 뺀 단지: `rental`(임대 단지), `unlisted`(목록과 이어지지 않은 실거래 `[구, 동, 단지명, 건수]`), `demolished`(철거 판별) |
| `trend` | 월별 시총·평당가 추이(서울·권역·구), 실거래 비율 |
| `volume` | 월별 거래량(구별) |
| `highs` | 최근 30일 신고가 `[단지 id, 전용㎡, 금액(만원), 이전 최고, 이전 최고 계약일, 계약일, 층]` |
| `history` | 날짜별 서울·구별 시총 스냅숏(일간 변동용) |

`complexes` 행의 열:

| 열 | 뜻 |
|---|---|
| `id` | 단지 코드(K-apt) |
| `name`, `aliases` | 단지명, 옛 이름·실거래 신고명 |
| `gu`, `dong` | 자치구, 법정동 |
| `type` | 서울시 목록의 분양 유형: `분양` · `임대+분양` · `혼합` · `기타` · 빈 값 |
| `households`, `area` | 세대수, 주거전용면적 합계(㎡) |
| `approved_year` | 사용승인 연도 |
| `trades`, `last_trade` | 12개월 거래 건수, 마지막 계약일 |
| `ppm` | ㎡당 중위가(만 원) |
| `basis` | 값의 근거: `trade` 실거래 · `presale` 분양권 · `dong` 같은 동 추정 · `gu` 같은 구 추정 · `null` 값 없음 |
| `value` | **시총(억 원)** |
| `chg`, `chg_n` | 같은 평형 12개월 등락(소수), 짝지어진 거래 수 |
| `brands` | 브랜드 |
| `lat`, `lng` | 좌표 |
| `sale_lo`, `sale_hi`, `jeonse_lo`, `jeonse_hi` | 12개월 매매·전세 가격대(만 원) |
| `sizes`, `main_size` | 평형(소·중·대)별 `[매매 하단, 상단, 전세 하단, 상단, 전세가율 %, 매매 건수, 전세 건수]`(금액은 억×10), 대표 평형 번호 |

```python
import json, urllib.request
d = json.load(urllib.request.urlopen("https://sojw.github.io/seoul-apt-dashboard/data.json"))
cols = d["complex_fields"]
rows = [dict(zip(cols, r)) for r in d["complexes"]]
top = sorted((r for r in rows if r["value"]), key=lambda r: -r["value"])[:5]
for r in top:
    print(f'{r["name"]:<12} {r["gu"]} {r["value"] / 10000:.1f}조')
```

### `trades/<구 코드>.json`

`{단지 id: [[계약일, 전용㎡, 층, 금액(만원), 해제 1/0, 직거래 1/0], ...]}` — 새 거래부터.

### `hist/<구 코드>.json`

`{"q": ["2016Q4", ...], "unit": "백만원", "rows": {단지 id: {"s"|"m"|"l": [분기 중위가 또는 null, ...], "hi": [[전용㎡, 금액(만원), 계약일], ...]}}}`
— `s`·`m`·`l` 은 소·중·대 평형, 없는 평형은 키가 없다. 값은 백만 원 정수(27.35억 → 2735).

### `rates.json`

| 키 | 내용 |
|---|---|
| `banks` | `[{id, name, major}]` — 앞 8곳이 주요 은행(`major: true`) |
| `kfb` | 은행연합회: `as_of`(기준 월말 'YYYY-MM'), `month`(공시월), `rows: {id: [대출금리, 기준금리, 가산금리, 가감조정금리]}`(값 없으면 null), `history: {months, rate: {id: [월별 대출금리]}}` |
| `finlife` | 금감원: `month`(공시월 YYYYMM), `rows: {id: {variable: [최저, 최고], fixed: [최저, 최고]}}` |
| `toss` | 토스뱅크: `date`, `min`, `max`, `bases: [{name, base, cycle(개월), min, max, add_min, add_max}]` |
| `errors` | 그날 갱신에 실패한 소스와 사유(그 소스는 직전 값) |

대출금리 = 기준금리 + 가산금리 − 가감조정금리. 항목마다 따로 낸 평균이라 더한 값이 대출금리와 조금 다를 수 있다.
값은 **전국 기준**이고, 실제 취급 평균이라 개인이 받는 금리와 다르다.

### `news.json` · `latest.json`

시각은 모두 유닉스 초. `news.json` 의 `clusters[]` 는 이야기 하나: `h` 제목, `s` 요약, `c` 분류, `seoul` 서울 이야기 여부,
`n` 보도한 곳 수, `a[]` 기사(`o` 언론사, `t` 제목, `u` 주소, `ts` 시각). `scoops[]`·`latest.json` 의 `items[]` 는 기사 목록이다.
요약과 묶음은 AI 가 만든 것이라 원문과 다를 수 있다 — 기사 원문 링크를 함께 둔다.


- 화면은 빌드 없는 `index.html` 한 장이고 Vercel 에만 있다(이 저장소의 `index.html` 은 넘김 페이지). 그래프는 SVG 로 직접 그리고, 지도는 카카오맵, 로그인·푸시는 Firebase. `sw.js` 는 앱 설치·푸시용 서비스 워커.
- Vercel 은 화면 코드만 들고, 데이터는 `vercel.json` 의 rewrite 로 이 저장소의 Pages 에서 받아 온다.
- `.nojekyll` 은 Pages 가 파일을 가공하지 않게 둔다.

## 이용 시 주의

- 투자 판단용 시세가 아니다. 공식 실거래를 일정한 규칙으로 모은 **추정치**다.
- 원자료의 이용 조건은 각 제공 기관(국토교통부·서울특별시·한국부동산원·전국은행연합회·금융감독원·토스뱅크)을 따른다. 기사 저작권은 각 언론사에 있다.
